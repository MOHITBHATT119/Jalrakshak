Security

Defense in depth

  • bcrypt password hashing (cost 12) — never plaintext comparison
  • JWT HS256: 30-min access + 7-day refresh with unique jti
  • Refresh rotation — old token revoked on use (replay protection)
  • Rate limit 10 logins/min/IP + full login audit trail (IP, UA, reason)
  • Password policy: ≥8 chars, letter + digit/special
  • Prod fail-fast on weak/default JWT secrets
  • Dual guards: React ProtectedAdminRoute + FastAPI require_admin on every mutating endpoint
  • Tokens in sessionStorage — die with the tab; 401 interceptor auto-redirects to login
